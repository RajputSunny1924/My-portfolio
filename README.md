# Personal Developer Portfolio

A modern, responsive developer portfolio built to showcase my projects, technical skills, development journey, and freelance web development services.

The portfolio serves as a professional platform where visitors can explore my work, learn about my development capabilities, view available services and pricing, and understand the terms and conditions of working with me.

It also includes dedicated pages for seasonal offers, website development pricing, and freelance service information.

## 🚀 Features

- Developer profile and introduction
- About Me section
- Technical skills and expertise
- Project showcase
- Project descriptions and technology information
- Freelance web development services
- Website development pricing
- Seasonal offers and promotions
- Terms and Conditions page
- Contact section
- Responsive user interface
- Mobile-friendly navigation
- React Router-based page navigation
- Route-specific SEO metadata
- Dynamic page titles and meta descriptions
- Canonical URLs
- Open Graph and Twitter Card metadata
- JSON-LD structured data
- SEO-friendly sitemap and robots.txt
- Optimized image and font loading
